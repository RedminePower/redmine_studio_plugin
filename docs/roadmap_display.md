# Roadmap Display

ロードマップのバージョン画面の「関連するチケット」を、ステータス・担当者・進捗率などの列と、担当者別・ステータス別などのグループ表示に置き換える機能です。

## 概要

Redmine 標準のバージョン画面では、チケットの題名と「終わったかどうか」しか分かりません。

<img src="images/roadmap_display_01.png" width="800">

この機能を使うと、同じ場所にチケット一覧と同じ形の表が表示されます。どの列を出すか・何でグループ化するかは、管理者が画面で選べます。

- ステータス・担当者・進捗率・更新日などの列を表示できる（チケット一覧で選べる列はすべて使える）
- 担当者別・ステータス別・トラッカー別などにグループ化でき、グループごとの件数が見える
- 終了したチケットは、標準のロードマップと同じく取り消し線で表示される
- 担当者には、標準のロードマップと同じ条件でアバターが付く
- 行を右クリックすると、チケット一覧と同じメニューで、ステータスや担当者をその場で変更できる
- 列の見出しをクリックすると並び替えられる

### ユースケース

- **リリースの進み具合を一目で確認** - ステータス別にまとめて、「作業中」「終了」がそれぞれ何件あるかを見る
- **誰の手が止まっているかを把握** - 担当者別にまとめて、更新日の古いチケットを見つける
- **会議でそのまま使う** - バージョン画面を開くだけで、チケット一覧の条件を組み直さずに状況を説明できる

## 表示される場所

### バージョン画面

ロードマップでバージョン名をクリックした先の画面です。「関連するチケット」が、設定した表示に置き換わります。

右側の「トラッカー」の枠でチェックを付け外しすると、その場で一覧を絞り込めます。絞り込んだ状態は URL に残るので、そのまま共有やブックマークができます。

<img src="images/roadmap_display_03.png" width="800">

- チェックボックスに出るのは、そのバージョンに実際にあるトラッカーだけです
- 最初はすべてチェックされた状態（絞り込みなし）で表示されます
- 列の見出しで並び替えても、絞り込みは解除されません

### ロードマップ画面

プロジェクトの「ロードマップ」タブ（すべてのバージョンが並ぶ画面）でも、バージョンごとに同じ表示に置き換わります。

<img src="images/roadmap_display_04.png" width="800">

右側の「ロードマップ」のトラッカーと「サブプロジェクト」の絞り込みは、標準の一覧と同じように効きます。

## 管理画面

管理者メニューの「ロードマップ表示」から、表示の設定（パターン）を作成・編集・削除できます。

<img src="images/roadmap_display_05.png" width="800">

| 列 | 説明 |
|----|------|
| 名称 | パターンの名前 |
| プロジェクトパターン | 対象にするプロジェクトの条件（正規表現）。空欄なら「(すべて)」 |
| 該当プロジェクト | このパターンが実際に使われるプロジェクトの数と名前 |
| 有効 | パターンの有効/無効 |

各行の右端から、並び替え（つまみをドラッグ）・コピー・削除ができます。

### パターンの照合の順番

1つのプロジェクトに使われるパターンは1つだけです。

- 一覧の **上から順に** 照合し、最初にプロジェクトパターンが当てはまったパターンを使います
- 並び順は、行の右端のつまみをドラッグして変えます
- どのパターンにも当てはまらないプロジェクトは、Redmine 標準の表示のままです
- 無効にしたパターンは照合されません

たとえば、上の画面では次のようになります。

| プロジェクト | 使われるパターン |
|-------------|----------------|
| RedmineStudio | ステータス別（`^redmine-studio$` に当てはまる） |
| Plugins・マーケティング・社内サポート | 担当者別（プロジェクトパターンが空欄 = 残りすべて） |

> **ヒント:** 個別のプロジェクト向けのパターンを上に、プロジェクトパターンが空欄の「その他すべて」向けのパターンを一番下に置くと分かりやすくなります。

> **補足:** パターンは、表示しているバージョンが属するプロジェクトで決まります。親プロジェクトのバージョンを子プロジェクトと共有している場合も、親プロジェクトのパターンで表示されます。

## 設定項目

### 基本設定

<img src="images/roadmap_display_06.png" width="700">

| 項目 | 説明 |
|------|------|
| 名前 | 管理上わかりやすい名前を設定（必須） |
| 有効 | パターンの有効/無効を切り替え |
| プロジェクトパターン | プロジェクトの **識別子** を正規表現で照合します。空欄ならすべてのプロジェクトが対象 |

プロジェクトパターンを入力すると、その下に **このパターンで表示されるプロジェクト** がその場で表示されます。保存する前に、意図したプロジェクトが対象になっているかを確認できます。

- 当てはまっても、上のパターンが優先されるプロジェクトは灰色で「対象外」と表示されます
- このパターンで表示されるプロジェクトが1つもない場合は、警告が表示されます

正規表現の書き方が正しくない場合は赤字で表示され、保存できません。

<img src="images/roadmap_display_07.png" width="700">

#### プロジェクトパターンの例

| 書き方 | 対象 |
|--------|------|
| （空欄） | すべてのプロジェクト |
| `^support-` | 識別子が `support-` で始まるプロジェクト |
| `^(redmine-studio\|plugins)$` | 識別子が `redmine-studio` または `plugins` のプロジェクト |
| `-dev$` | 識別子が `-dev` で終わるプロジェクト |

> **注意:** 照合するのはプロジェクトの **名前ではなく識別子** です。識別子は、プロジェクトの「設定」タブで確認できます。

### 一覧の表示

チケット一覧の「オプション」「ソート条件」「項目」と同じ部品で選びます。

<img src="images/roadmap_display_08.png" width="700">

| 項目 | 説明 |
|------|------|
| グループ条件 | 担当者・ステータス・トラッカーなどでグループ化。空欄ならグループ化しない |
| 対象のチケット | 「すべて」「未完了のみ」「完了のみ」から選択 |
| 合計 | 一覧の上に合計を表示する項目（予定工数・作業時間など） |
| 標準の一覧 | Redmine 標準の「関連するチケット」を「隠す」か「下に残す」か |
| ソート条件 | 並び順（3つまで）。グループ化している場合は、グループの中での並び順になる |
| 項目 | 表示する列と、その並び順 |

> **補足:** 「#」（チケット番号）の列は、チケット一覧と同じく常に表示されます。

### プレビュー

保存する前に、編集中の内容でバージョンの表示を確認できます。バージョンを選んで「プレビュー」をクリックしてください。

<img src="images/roadmap_display_09.png" width="700">

### 標準の一覧を残す場合

「標準の一覧」を「下に残す」にすると、設定した表示の下に Redmine 標準の「関連するチケット」も表示されます。

<img src="images/roadmap_display_10.png" width="800">

## 対応 Redmine

- V5.1 / V6.1 / V7.0 で動作確認済み
- 担当者のアバターは、標準のロードマップと同じ条件で表示されます。Redmine 6.0 以降は画像が無い人にもイニシャルのアバターが出ますが、Redmine 5.x では Gravatar を有効にしている場合だけ表示されます
