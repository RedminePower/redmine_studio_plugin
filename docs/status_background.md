# Status Background（ステータスによるチケットの背景色）

チケットの詳細画面で、説明などの枠の背景を、ステータスに合わせた色にする機能です。

## 概要

Redmine のチケット詳細画面は、ステータスが終了でも、説明などの枠が進行中のチケットと同じ黄色のままです。終わったチケットかどうかは、ステータスの欄を読むまで分かりません。

この機能を有効にすると、終了扱いのステータス（完了・却下など）のチケットは、枠の背景が薄いグレーになります。開いたときに「もう終わった話」とすぐ分かります。

入れただけでは見た目は変わりません（初期値は無効）。利用者への案内を済ませてから、管理者が有効にしてください。

### 主な機能

- 有効にするだけで、終了扱いのステータスのチケットは薄いグレーになる（色を選ばなくてよい）
- ステータスごとに、背景色を候補の色（薄いグレー・薄い青・薄い緑・薄い赤）から選べる。色を指定することもできる
- 文字の色は変えない。終了したチケットでも、コメントを読んだり書いたりしやすいまま
- 再オープンしたら、戻したステータスの色になる
- 終了扱いかどうかは、ステータスの「終了したチケット」の設定で決まる。ステータスの名前には頼らないので、独自のステータスにもそのまま効く

## 使い方

1. 管理 → プラグイン → Redmine Studio plugin の「設定」を開く
2. 「ステータスによるチケットの背景色」の「背景色を変える」にチェックを入れる
3. 必要なら、ステータスごとに背景色を選ぶ
   - 「(変えない)」を選ぶと、そのステータスは元の色のまま
   - 「色を指定」を選ぶと、右に色を選ぶ欄が出る
4. 「適用」をクリック

元に戻したいときは、「背景色を変える」のチェックを外します。チェックを外している間も、選んだ色は保存されています。

## 対象の画面

チケットの詳細画面だけです。チケット一覧の行の色は変えません。

Redmine 標準のテーマと farend_basic テーマで、選んだ色になることを確かめています。
