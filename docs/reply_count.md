# Reply Count（返答回数）

チケット一覧に「返答回数」カラムを追加する機能です。

## 概要

チケットの担当者が何回切り替えられたかを「返答回数」として表示します。返答回数が多いチケットは、要件の認識齟齬やレビュー指摘の多さを示唆する指標として活用できます。

### 主な機能

- チケット一覧に返答回数をインラインカラムとして表示
- 返答回数でソート可能（デフォルトは降順）
- カーソルを合わせると担当者の変更履歴をツールチップで表示
- 本プラグイン専用エンドポイント（`GET /issues_with_extras/:id.json` / `.xml`、`GET /issues_with_extras.json` / `.xml`）で `reply_count` フィールドを含めたレスポンスを返す

### API レスポンス形式

`reply_count` は `count`（返答回数）と `items`（担当者の遷移）のネストオブジェクトで返します。`items` は表示の元情報であり、ラベル化などの整形はクライアント側で行います。

```json
"reply_count": {
  "count": 3,
  "items": [
    { "id": 2, "name": "田中 太郎" },
    { "id": 3, "name": "佐藤 花子" },
    { "id": 2, "name": "田中 太郎" },
    { "id": 0, "name": "" }
  ]
}
```

- `items` は「初期担当者 → 変更ごとの新担当者」の順（要素数 = `count` + 1）
- 担当者なしは `id: 0, name: ""`、削除済み等の無効ユーザーは `id: 元のID, name: ""`
- 担当者変更が一度もないチケットは `count: 0`、`items` は現在の担当者 1 件

## 使い方

### チケット一覧画面

1. チケット一覧の「オプション」を開く
2. 「利用できる項目」から「返答回数」を「選択された項目」に追加
3. 「適用」をクリック

## 返答回数のカウントルール

- 担当者が変更されるたびに +1
- 担当者なし → ユーザー = +1（初回設定も含む）
- ユーザー → 担当者なし = +1（クリアも含む）
- チケット作成時の担当者設定は返答回数に含まない（初期状態）
- 一度も変更がない場合 = 0

## ツールチップ

返答回数にカーソルを合わせると、担当者の変更履歴がツールチップで表示されます。

**表示例（返答回数 = 3）:**
```
田中 太郎
 - 佐藤 花子
 - 田中 太郎
 - （担当者なし）
```

- 1行目（インデントなし）: チケット作成時の初期担当者
- 2行目以降（` - ` 付き）: 担当者の変更先
- 担当者が設定されていない場合は「（担当者なし）」と表示
- 削除済みユーザーは「（担当者なし）」と表示
